## 变量作用域

### 有哪些作用域

- **全局变量**：定义在函数方法外的位置，在全局的范围有效
- **局部变量**：定义在函数方法内的位置，在局部范围有效

### 有全局变量与局部变量重名

函数内优先使用局部变量；

如果找不到局部变量，才会使用全局变量：

- 只能读取全局变量的值
- 不能直接修改全局变量的值

### 在函数内如何修改全局变量值

在函数内使用 `global 变量名`，然后再使用这个变量就是全局变量了。

## 传参方式

### 位置参数

- **传参语法**：`函数名(实参值, 实参值, ...)`
- **注意**：
  - 实参的数量要求：个数较少
  - 实参的顺序要求：必须按照位置一一对应
- **适用场景**：形参少且容易简明知意

### 关键字参数

- **传参语法**：`函数名(参数1=值, 参数2=值, ...)`
- **注意**：
  - 传参的顺序：不需要固定顺序，可按需修改
  - 传参的数量：部分参数可空，不确定参数数量
- **适用场景**：形参较多且难以见名知意

## 函数形参

### 默认参数

- **指**：函数里带默认值的形参
- **效果**：
  - 调用函数时，如果给默认参数传递的实参，实际使用的是默认值
  - 调用函数时，如果没有给默认参数传参，将会使用实参
- **语法**：`函数名(形参1=默认值, 形参2=默认值)`
- **注意**：默认参数要放到非默认参数的后边

## 匿名函数

- **指**：没有名字的函数，要写成 `lambda` 的形式
  - `lambda` 形式只关注函数的形参、函数体
  - 不需要 `def` 关键字、不需要函数名、不需要写 `return`
- **语法**：`lambda 形参1, 形参2 : 函数方法`
- **适用场景**：不需要重复使用的代码块，且实现方法较少

## 类型注解

- **作用**：声明变量时直接声明它的类型，如果存储的值和类型不符，会给出警告
- **好处**：可以更快的发现问题

### 变量的类型注解，语法

变量只允许存储一种类型的数据：

```python
变量: 类型 = 值
```

变量允许存储多种类型的数据：

```python
变量: 类型1 | 类型2 | 类型3 = 值
```

变量如果允许空值 `None`：

```python
变量: None = 值
```

列表类型的变量：

```python
变量: list[元素的类型]
```

元组类型的变量：

```python
变量: tuple[值1的类型, 值2的类型, ...]
```

字典类型的变量：

```python
变量: dict[键类型, 值类型]
```

### 函数的类型注解，语法

函数需要有 2 个地方添加类型注解：形参、返回值。

**语法：**

```python
def 函数名( 形参: 类型, 形参: 类型, ... ) -> 返回值类型:
    函数体代码
```

## 模块

- **什么是模块**：一个含有固定功能的 `.py` 文件，模块的名称是 `moudel`
- **需要使用某个模块里的功能，就需要导入**：
  - 导入整个模块：`import 模块名`
  - 导入整个模块并起别名：`import 模块名 as 别名`
  - 从模块中导入自己需要的功能：`from 模块名 import 功能名`
  - 从模块里导入自己需要的功能并起别名：`from 模块名 import 功能名 as 别名`
  - 从模块里导入所有公共的功能：`from 模块名 import *`

### 如何自定义模块

- 创建一个 `.py` 文件
- 在 `.py` 里定义数据、函数等等
- 在 `.py` 里建议增加 `__all__ = ["功能1", "功能2", ...]`
  - **作用**：用于声明要暴露出去的功能
  - **注意**：其它文件里导入此模块时，如果用 `from 模块名 import *`，实际导入的功能是由 `__all__` 决定的
