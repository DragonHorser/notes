## DML

### 插入数据记录

#### 给所有字段设置值

```sql
insert into 表名 values (值1, 值2, ...), (值1, 值2, ...), ...
```

- **注意**：`values` 后边每个 `()` 是一行数据，数据值的个数、顺序、类型必须和表里字段的个数、顺序、类型完全匹配
- **提示**：如果某个字段必须提供值，可是又没有值可提供，可以使用 `null`
- **提示**：MySQL 可以使用字符串为任意类型字段赋值

#### 给指定字段设置值

```sql
insert into 表名(字段1, 字段2, ...) values (值1, 值2, ...), (值1, 值2, ...), ...
```

- **注意**：`values` 后边每个 `()` 是一行数据，数据值的个数、顺序、类型必须和前边字段的个数、顺序、类型完全匹配

### 修改数据记录

```sql
update 表名 set 字段1=值1, 字段2=值2, ... where 条件
```

- **作用**：根据 `where` 条件定位到数据行，将这些数据行里的字段值进行修改

### 删除数据记录

```sql
delete from 表名 where 条件
```

- **作用**：根据 `where` 条件定位到数据行，将这些数据行删除掉

## DQL

### 综合语法

```sql
select 字段列表
from 表名列表
where 条件
group by 分组条件 having 分组后的过滤
order by 排序条件
limit 分页条件
```

### 基础查询

**查询指定列的数据：**

```sql
select 字段1, 字段2, ... from 表名
```

**查询所有列的数据：**

```sql
select * from 表名
```

**查询时给列起别名：**

```sql
select 字段1 as 别名1, 字段2 as 别名2, ... from 表名
select 字段1 别名1, 字段2 别名2, ... from 表名
```

**查询时进行数据计算：**

- **注意**：在 SQL 语句里只做最基础简单的计算，不要有复杂计算，会影响 SQL 语句执行的效率
- **注意**：查询语句里的任何计算操作，不会导致表里的数据变更

```sql
select 字段1 + 值, 字段2 - 值, ... from 表名
```

**查询时要求去重：**

```sql
select distinct 字段1, 字段2, ... from 表名
```

### 条件查询

`where` 条件的作用：用于筛选/定位数据行的。

**单个条件的写法：**

- 等于：`字段 = 值`
- 不等于：`字段 <> 值` 或 `字段 != 值`
- 比较：`字段 > 值` 或 `字段 >= 值` 或 `字段 < 值` 或 `字段 <= 值`
- 区间：`字段 between 开始值 and 结束值`（包含开始值和结束值）
- 枚举：`字段 in (值1, 值2, ...)`
- 模糊匹配：`字段 like '表达式'`
  - 表达式里：`_` 表示 1 个任意字符
  - 表达式里：`%` 表示任意个任意字符
- 模糊排除：`字段 not like '表达式'`
  - 表达式里：`_` 表示 1 个任意字符
  - 表达式里：`%` 表示任意个任意字符
- 为空：`字段 is null`
- 不为空：`字段 is not null`

**多个条件的连接：**

- 并且：`and`
- 或者：`or`
- 取反：`not`
