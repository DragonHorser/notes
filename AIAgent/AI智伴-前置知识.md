一、网络协议
1. IP
IP地址：计算机设备在网络里的唯一标识（身份证）

IP作用：根据 IP 从网络里找到某一台计算机设备

IP分类：

IPv4：示例 192.168.40.117

IPv6：冒号分隔的十六进制值，如 1234:abcd:a1b2:...

需要掌握：

查看本机 IP：ipconfig

始终指向本机的 IP：127.0.0.1 或 localhost

2. 端口
作用：计算机里的软件与外界进行数据交互时的虚拟出入口

范围：0 ~ 65535

特点：抢占式资源

一个端口被某个程序占用后，其它程序不能再占用

例如：3306 端口被 MySQL 使用

3. HTTP
全称：超文本传输协议

作用：规定客户端和服务端之间数据交互的格式

特点：

基于文本：所有交互数据都是字符串，底层 TCP 稳定可靠

请求驱动：先有请求，才有响应

请求：客户端发给服务端的数据

响应：服务端返回客户端的数据

无状态：两次请求之间，后端没有记忆

HTTP 请求
前端发送给后端的数据，由三部分组成：

请求行
本次请求的基本信息

格式：请求方式 请求资源 协议版本

示例：GET /courses/1 HTTP/1.1

请求方式：

查询：GET

新增：POST

修改：PUT

删除：DELETE

请求头
本次请求的附加信息（很多由浏览器自动附加）

格式：一行一个键值对，用英文冒号分隔

请求体
本次请求提交的正文数据

POST 或 PUT 时提交的数据（要保存或修改的数据）

GET 和 DELETE 没有请求体，提交的数据写到请求行里请求资源的后边

HTTP 响应
后端返回给前端的数据，由三部分组成：

响应行
本次响应的基本信息

格式：协议版本 响应状态码

响应状态码：3 位整数，告诉前端本次处理结果

1xx：过程码，通常见不到

2xx：成功码

3xx：告诉前端需要下一步操作

304：后端告诉前端去找缓存数据

4xx：前端出错

400：Bad Request

403：没有权限访问

404：请求的资源不存在，检查路径

5xx：后端出错

500：服务器内部错误

503：后端服务不可用

响应头
本次响应的附加信息

格式：一行一个键值对，用冒号分隔

响应体
本次响应的正文内容，是后端返回给前端的结果数据

大模型本身没有记忆

让它具备记忆功能的方法：

上下文拼接：每次发消息时，把历史聊天记录一起发送

滑动窗口：只附带最近 n 条聊天记录，防止上下文无限膨胀

RAG + 数据库：利用数据库和 RAG 实现长期记忆

三、FastAPI
1. 作用
将一个普通函数变成 API 接口，其他人可以通过网络调用执行

2. 使用入门
添加依赖包：uv add fastapi uvicorn

创建一个 .py 模块：

编写普通函数

创建 FastAPI 实例：app = FastAPI()

在函数上加装饰器：@app.get("/访问路径")

启动服务监听端口：

方式1：命令行执行

bash
uvicorn '模块名:FastAPI实例名' --host=0.0.0.0 --port=端口
方式2：在 .py 里添加

python
if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
访问 API 接口：

浏览器输入：http://服务器IP:端口/功能的路径

3. Pydantic
用于制定数据模型的规范，由 FastAPI 帮我们校验数据

用法：

编写模型类，必须继承 BaseModel
python
class User(BaseModel):
    属性名: 类型 = 默认值
在 API 接口里：
接收前端提交的数据

4. Swagger
用于为 API 接口生成说明文档，还可直接测试接口

用法：

app = FastAPI(title="文档标题", description="项目描述")

在接口装饰器上增加说明：

python
@app.get("/users", summary="功能描述", response_model=响应数据类型)
查看文档：http://服务器IP:端口/docs

四、同步和异步
对比
类型  特点  说明
同步  阻塞、等待、串行  执行一步操作必须等待结果，拿到结果才继续；等待过程中什么都不做
异步  非阻塞、不等待、并行  执行一步操作不等待结果，CPU 可以去做其它事情
