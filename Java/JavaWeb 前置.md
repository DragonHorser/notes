## day01‑HTML（网页骨架）
**学习目标**：搭建网页基础结构，掌握各类基础标签、路径写法。

### 核心知识点 & 用法
1. HTML文档基础模板，所有html页面必须包裹这套结构
```html
<!DOCTYPE html>
<html>
<head>
    <!-- 网页标题、元数据 -->
</head>
<body>
    <!-- 页面所有可见内容写在这里 -->
</body>
</html>
```

2. 路径写法
- 相对路径
  - `./a.jpg`：当前目录下的 a.jpg，`./`可以省略
  - `../a.jpg`：上一级目录的 a.jpg，每一个`../`代表向上跳一级文件夹
- 绝对路径：完整 http/https 网络地址，例如`https://xxx.com/1.jpg`
3. 文本标签
- `<h1>~<h6>`：标题标签，h1 最大，h6 最小
- `<p>`：段落标签，实现段落换行间距
- `<b>`：文字加粗
- `<i>`：文字斜体
4. 媒体标签
- `<img src="图片地址">`展示图片；src 属性写图片路径，可以追加`alt`图片加载失败提示文字
5. 超链接
- `<a href="跳转地址">文字</a>`页面跳转；href 填写目标地址
6. 列表标签
- 无序列表：`<ul><li>列表项</li></ul>`，不带数字序号
- 有序列表：`<ol><li>列表项</li></ol>`，自带 123 序号

✅ **当日任务**：写一个简单网页，包含标题、图片、超链接、列表。

## day02‑HTML & CSS（网页样式）

**学习目标**：掌握表格、表单标签；CSS 三种引入方式、选择器、盒子模型，能给页面美化样式。

### 核心知识点 & 用法

1. 表格标签 `<table>`
- `<tr>`代表一行
- `<td>`代表单元格

```
<table>
    <tr>
        <td>单元格1</td>
        <td>单元格2</td>
    </tr>
</table>
```

2. 表单标签 `<form>`：收集用户输入的数据，提交给服务器
- `<input>`输入框，可以设置 type 属性实现普通输入框、单选框 radio、复选框 checkbox、提交按钮 submit
3. CSS 三种引入方式
   1）行内样式：直接写在标签 style 属性上

```
<div style="color:red;">文字</div>
```

2）内部样式：写在 head 标签内的`<style>`标签

```
<head>
  <style> div{color:red;} </style>
</head>
```

3）外部样式（项目开发推荐）：独立`.css`文件，link 标签引入

```
<link href="xxx.css" rel="stylesheet">
```

4. 基础选择器
- 标签选择器：`div {}`，选中页面全部 div 标签

- id 选择器：`#id名 {}`，对应标签`id="xxx"`，id 页面唯一

- class 类选择器：`.类名 {}`，标签写`class="xxx"`，开发最常用，一个标签可以多个 class
5. CSS 常用属性
- `color`：文字颜色

- `font‑size`：字号大小

- `width / height`：元素宽高
6. 盒子模型

> content 内容 + padding 内边距 + border 边框 + margin 外边距

- content：盒子里面存放内容区域
- padding：内容和边框之间距离（内边距）
- border：边框
- margin：盒子与外部其他元素之间距离（外边距）

✅ **当日任务**：做一个简单登录表单，加上样式美化。

## day03‑JS 基础语法（JavaScript 脚本逻辑）

JS 作用：给网页增加交互逻辑。

1. 输出语句

3. 数据类型

4. 变量 / 常量
- `let a = 10;`：变量，后续可以修改值

- `const b = 20;`：常量，定义后不允许修改
5. 运算符
- 算术运算符：`+ - * / %`

- 比较运算符：`> < == !=`

- 逻辑运算符：`&&`与、`||`或、`!`非
6. 分支语句

```
if(条件){

}else if(条件){

}else{

}

switch(值){
  case xxx:
    break;
}
```

7. 循环语句

```
//while循环
while(条件){ }
//do‑while
do{ }while(条件);
//for循环

```

8. 函数：封装可复用代码

```

    //函数体逻辑

fn(); //调用函数
```

9. 事件绑定：`onclick`点击事件，标签绑定点击执行 js 代码

```
<button onclick="fn()">点我</button>
```

## day07‑MySQL 基础（数据库入门）

**学习目标**：理解数据库模型，掌握 DDL 库表操作，DML 增删改，会建库建表插入修改删除数据。

### 核心知识点 & 用法

1. 常见数据库：MySQL (开源主流)、Oracle、SQLServer
2. MySQL 层级模型：数据库 → 数据表 → 行 (记录)、列 (字段)
3. 工具：MySQL 服务 + Navicat 可视化客户端
4. SQL 四大分类
- DDL：操作库、表结构
- DML：增删改表数据 `insert update delete`
- DQL：查询数据 `select`
- DCL：账号权限管理

#### 数据库操作 DDL

```
create database 库名; -- 创建数据库
drop database 库名; -- 删除数据库
use 库名; -- 使用指定数据库
```

#### 表操作 DDL

```
create table 表名(字段名 数据类型 约束, ...);
drop table 表名; -- 删除表
```

常用数据类型

- `int`整数、`varchar(长度)`字符串、`date`日期、`decimal`小数

常用约束

- `primary key`主键，唯一标识记录
- `not null`非空，字段不能为 null
- `unique`唯一，字段值不能重复
- `default`设置字段默认值

#### DML 增删改

```
-- 插入
insert into 表(列1,列2) values(值1,值2);
-- 修改
update 表 set 列=值 where 条件;
-- 删除
delete from 表 where 条件;
```

## day08‑MySQL 单表查询（DQL 重点，面试高频）

**学习目标**：熟练掌握 select 查询语法，条件查询、聚合函数、分组、排序、分页。

### 核心知识点 & 用法

完整查询语法顺序

```
select 字段 from 表
where 条件
group by 分组字段
having 分组后过滤
order by 排序字段 asc|desc
limit 起始索引,每页条数;
```

1. 基础查询`select * from 表`查询全部字段；指定列查询；`as`别名；`distinct`去重
2. where 条件查询
   运算符：`> < = != and or`；`like`模糊查询；`in`；`is null`判断空值
3. 聚合函数，用于统计`count()`计数、`sum()`求和、`avg()`平均值、`max()`最大值、`min()`最小值
4. 分组统计 `group by`
- where：分组**之前**过滤原始数据
- having：分组**之后**，对分组结果过滤
5. 排序 `order by``asc`升序，`desc`降序
6. 分页查询 `limit 起始索引,每页条数`；后端业务分页必用

✅ **当日任务**：练习各类 DQL 查询 SQL，熟练 where/group by/order by/limit。

## day09‑MySQL 多表（重点难点）

**学习目标**：理解表之间关系；掌握内连接、外连接、子查询；会处理一对多、多对多场景。

### 核心知识点 & 用法

1. 表关系
- 一对多：例如部门 (1)，员工 (多)；员工表存放外键保存部门 id
- 多对多：学生‑课程，新建一张中间关联表，保存双方主键
- 一对一：用户‑用户详情，主键一一对应

> 物理外键约束：保证关联完整性；企业开发经常不开启物理外键，用代码逻辑维护关系（逻辑外键）

2. 笛卡尔积：两张表直接查询，全部数据无序组合；多表查询必须消除笛卡尔积，使用 on 关联条件
3. 内连接 inner join，只查询两边匹配成功数据

```
select * from A inner join B on A.id = B.a_id;
```

4. 外连接
- 左外连接 `left join`：左边表全部数据，匹配右边表数据，没有匹配填充 null
- 右外连接 `right join`：右边表全部数据，匹配左边表数据
5. 子查询：select 内部嵌套 select 语句，结果充当条件 / 临时表
6. `case…when`：SQL 中实现 if‑else 分支判断

✅ **当日任务**：练习一对多、多对多建表；写内连接、左连接、子查询。

## day10‑MySQL 事务、索引、HTTP、Ajax 前置

**学习目标**：掌握事务 ACID、索引作用；理解 HTTP 协议；搞懂同步请求与 Ajax 异步。

### 核心知识点 & 用法

1. 事务：一组 SQL，要么全部执行成功，要么全部失败回滚。用于转账等场景，保证数据安全。
- ACID 四大特性（面试必背）：原子性、一致性、隔离性、持久性
- 事务操作 SQL

```
start transaction; --开启事务
commit; --提交事务，永久生效
rollback; --回滚，撤销全部操作
```

- 四大隔离级别：解决脏读、不可重复读、幻读问题
2. 索引
- 作用：提升查询速度；主键自带索引
- 创建索引 `create index 索引名 on 表(字段)`
- 缺点：索引会降低增删改的执行速度
3. JDK 安装，启动后端项目，看懂接口
4. HTTP 协议：浏览器与服务器通信规则
- 请求：请求行、请求头、请求体
- 响应：响应行、响应头、响应体
5. 同步 vs 异步
- 同步请求：整个页面刷新
- Ajax 异步：JS 发送请求，局部刷新页面，不用刷新整个网页

✅ **当日任务**：手动写事务 commit/rollback；理解同步异步区别；写简单 Ajax 请求。
