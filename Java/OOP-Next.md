## 方法重载

### 多个方法什么情况下构成重载

在同一个类里，满足以下条件即构成重载：

- 同名
- 不同参
  - 参数数量不同
  - 参数类型不同
  - 参数顺序不同

> **注意**：和形参名称没有关系，形参名可以任意修改。

### 方法重载的好处

对方法的使用者有好处，减轻记忆负担。

## OOP 基本语法

### 创建类

```java
public class 类名{
    属性类型 属性名;
    属性类型 属性名;

    返回值类型 方法名(形参类型 形参名, ...){
        方法体完成功能;
        return 结果值;
    }
}
```

**注意：**

- 类名的命名：采用大驼峰
- 方法名、属性名：采用小驼峰

### 创建对象

```java
new 类名()
```

### 使用对象

**使用对象的属性：**

- 取属性值：`对象变量名.属性名`
- 改属性值：`对象变量名.属性名 = 值;`

**使用对象的方法：**

```java
对象变量名.方法名(实参列表)
```

## JVM 内存划分

JVM 申请到的内存，根据职责又划分了 5 种区域：

| 区域 | 职责 |
| --- | --- |
| 方法区 | 我们的类代码、方法代码都在方法区里 |
| 栈（方法栈） | 用于运行方法代码的。任何方法要运行，就必须要入栈；运行完毕再出栈 |
| 堆（堆内存） | 用于放所有 `new` 出来的对象 |
| PC 计数器 | 用于记录程序执行的位置，便于 CPU 切换执行不同程序时，可以继续执行而不是从头开始执行 |
| 本地方法栈 | 用于让 JVM 和操作系统交互的 |

## 封装思想

指：将数据封装到属性，将功能代码封装成方法，然后通过 `public` 和 `private` 控制隐藏与暴露。

### public

- 可以修饰属性和方法
- 被 `public` 修饰的属性和方法：在任何地方都可以调用

### private

- 可以修饰属性和方法
- 被 `private` 修饰的属性和方法：只能在类内部自己使用

### 实际开发规范

- 所有成员变量（属性）全部设置为 `private` 私有的
- 再给每个私有的成员变量提供 `public` 的 `get` 和 `set` 方法
  - 使用 `Alt + Insert` 自动生成

### this

- 如果在方法里直接使用变量名操作：就近
  - 如果方法内有此变量，使用的是方法内的局部变量
  - 如果方法里没有此变量，将会查找成员变量
- 如果在方法里使用 `this.变量名` 操作：
  - 明确指定要操作的是成员变量

### 构造方法

**作用**：可以在创建对象时进行初始化，可以为各成员变量直接赋值。

**执行时机**：在通过 `new` 创建对象时，会执行构造方法。

**定义语法：**

要求：

- 构造方法名必须和类名相同
- 构造方法不需要返回值类型，连 `void` 都不写
- 构造方法里不能有 `return 结果值;`
- 构造方法可以重载

注意：

- Java 类里如果没有构造方法，Java 会提供一个隐含的无参构造
- 一旦类里添加了构造方法，Java 就不再提供隐含的无参构造了

开发习惯：

1. 创建类，定义私有的成员变量
2. 然后定义构造方法：
   - 使用 `Alt + Insert` 生成无参构造
   - 使用 `Alt + Insert` 生成全参构造

## 继承思想

**作用**：用于消除类之间重复成员的问题。

### 语法

```java
public class 类 extends 父类{
    增加自己独有的成员变量和方法
}
```

> 子类继承父类，子类继承父类里非私有的成员。

### 特点

- **单继承**：一个类只允许有一个父类
- **多层继承**：类可以有父类，父类也可以有自己的父类
- **Object 是万类之祖**：所有类都直接或间接的继承自 `Object` 类

### 方法重写

当从父类继承来的方法不满足要求时，可以重写父类的方法。

- **重写的要求**：父子类重写的方法，必须是同名同参
- **常需重写的方法**：`toString()`，打印类或实例时打印输出的值可以自己定义
