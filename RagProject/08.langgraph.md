## 简介

LangGraph 是一个智能体编排框架，可以在 LLM 自主控制的前提下，保证整个应用程序的稳定。

具体的方式：定义一个流程图（工作流），不是单向的，而是可以有分支、有循环多向图。

构成的要素：

| 要素 | 说明 |
| --- | --- |
| 节点 node | 每个节点用于完成任务，由我们编写代码 |
| 边 edge | 理解为图里的箭头，决定节点的走向 |
| 状态 state | 用于在整个图中共享数据的 |

## 入门

### 第1步：先准备 State 类

**作用**：定义在整个流程图中共享的数据模型。

**写法**（继承于 `TypedDict`）：

```python
class 类名(TypedDict):
    属性名: 类型
    属性名: 类型
    ....
```

**注意：**

- 在流程中，每个节点都可以更新数据，默认更新方式：新值覆盖旧值
- 如果更新数据时，想要自定义更新的逻辑：可以自定义归约器 Reducer

```python
class 类名(TypedDict):
    num: int
    nodes: Annotated[类型, 归约函数]
```

```python
class 类名(TypedDict):
    num: int
    nodes: Annotated[list[str], add]
```

- `num` 数据没有自定义归约器：节点中更新 `num` 值时，新值将会覆盖旧值
- `nodes` 数据定义了归约器：`+`。节点中更新 `nodes` 时，将会旧值 + 新值

### 第2步：再定义节点 Node

**作用**：用于完成一项任务。

**写法：**

```python
def 函数名(state: State类):
    通过state对象可以得到数据
    利用数据完成功能
    return { "数据名称": 值 }
```

`return` 的结果：表示要更新 state 对象里的数据。

### 第3步：构建成图 Graph

```python
builder = StateBuilder(State类)
```

**添加节点：**

```python
builder.add_node('节点名称', 节点函数名)
```

**添加边（箭头）：**

添加普通边：

```python
builder.add_edge( 起始节点名, 目标节点名 )
```

> 效果：一定会执行从起始节点到目标节点的流程。

添加条件边：

```python
builder.add_conditional_edge(起始节点名, 路由函数名)
```

```python
def 路由函数名(state: State类):
    处理……
    return 目标节点名
```

定义节点时，节点直接返回 `Command` 对象，不需要条件边：

```python
def 节点函数(state: State类):
    ……
    return Command(
        update={'数据项': 值},
        goto=下一节点的名称
    )
```

**生成图：**

```python
graph = builder.compile()
```

### 第4步：调用图 Graph

```python
graph.invoke( input={初始数据} )
```

## 构建智能体

### 第1步：准备 State 对象

LangGraph 提供 `MessagesState`，我们直接使用即可。

`MessagesState` 中规定了数据项：`messages`

- 类型是：`list[ AnyMessage ]`
- 数据归约：`add_messages` 函数，即追加

### 第2步：准备 Node 节点

**大模型节点：**

```python
def 函数名(state: MessagesState):
    ai_message = model.invoke( state['messages'] )
    return {'messages': [ai_message] }
```

**工具节点：**

- 调用工具、得到结果的节点
- 不需要我们定义，LangGraph 提供了 `ToolNode( [工具函数名, 工具函数名, ...] )`

**其它节点：**

- 普通节点

### 第3步：构建成 Graph 图（智能体）

```python
builder = StateGraph(MessagesState)
```

**添加节点：**

添加普通节点：

```python
builder.add_node('节点名', 节点函数名)
```

添加工具节点：

```python
builder.add_node( 'tools', ToolNode( 工具函数名列表 ) )
```

**添加边：**

添加普通边：

```python
builder.add_edge(起始节点名, 目标节点名)
```

大模型节点后如果要判断是否要调用工具，添加条件边：

```python
builder.add_conditional_edges('模型节点名', tools_condition)
```

其中 `tools_condition` 是路由函数：

- 如果模型最后回复的消息中有工具调用信息：目标节点是 `tools`
- 如果模型最后回复的消息中没有工具调用：目标节点是 `END`

**构建智能体：**

```python
agent = builder.compile( checkpointer=记忆存储位置 )
```

- `InMemorySaver()`：临时存储到内存中
- `PostgresSaver()`：长期存储到本地的 PG 数据库内

### 第4步：使用智能体 Graph

**普通调用：**

```python
res = agent.invoke(
     input={ 'messages': [ HumanMessage(content='用户问题') ] },
     config={ 'configurable': {'thread_id': '会话id'} }
)
```

阻塞式输出：

```python
for msg in res["messages"]:
    msg.pretty_print()  # 美化输出
```

**流式输出：**

```python
stream = agent.stream_events(
     input={ 'messages': [ HumanMessage(content='用户问题') ] },
     config={ 'configurable': {'thread_id': '会话id'} },
     version='v3'
)
```

流式输出：

```python
for msgs in stream.messages:
    for msg in msgs.text:
        print(msg, end="", flush=True)
```
