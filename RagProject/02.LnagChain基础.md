## Agent 简介

### ReAct 模型

Reasoning 思考 -> Action 行动 -> 观察结果

如果结果不足以回答问题，则重新开始上述过程。

### Agent 交互过程

1. 用户提问，问题交给 Agent
2. Agent 拼接：用户的问题 + 工具的信息，交给 LLM
   - LLM 根据用户问题思考，要调用哪个工具
   - 将思考结果（要调用哪个工具，工具需要的参数）返回给 Agent
3. Agent 执行：调用工具，得到结果
4. Agent 再调用 LLM：将工具的结果和聊天记录（包含用户问题）给 LLM
   - 根据工具结果判断是否足以回答用户的问题
   - 如果可以回答了，就生成最终的回复给 Agent
5. Agent 得到回答，将回答返回给用户
6. 用户得到答案

## LangChain 直接调用模型

**步骤：**

```python
#1. 加载配置参数，参数会被临时放到环境变量里
load_dotenv()

#2. 初始化模型
model = init_chat_model(
        model="模型名称",
        extra_body={"thinking":{"type":"disabled"}}
  )

#3. 调用模型。response里content是AI回复的消息内容
response = model.invoke("用户消息")
```

### 不同模型的用法

**原生集成的模型：**

- 使用最便捷，LangChain 内置了 `base_url`，会自动读取环境变量得到 `api_key`。只要配置模型名称即可

```python
model = init_chat_model(model="模型名称")
```

**协议兼容的模型：**

- 如果模型没有被 LangChain 原生集成，但提供 openai 协议的访问接口，可以采用这种方式
- 国产模型平台，几乎全部提供了兼容 openai 协议的访问接口
- 初始化模型增加几个参数：

```python
init_chat_model(
     model = "模型名称",
     model_provider = "openai",
     base_url = "地址",
     api_key = "APIKey"
)
```

**专属适配的模型：**

- LangChain 没有原生集成，又没有提供 openai 兼容的访问接口
- 通常是：本地部署的模型，比如使用 Ollama 在本地运行的模型

### 消息对象的构造

- 构造系统人设与回复逻辑：`SystemMessage(content="系统人设与回复逻辑")`
- 构造用户的消息：`HumanMessage(content="用户的问题")`
- AI 回复的消息：`AiMessage(content="....")`

## LangChain 创建智能体

### 使用方式1：阻塞式输出

```python
#1. 加载配置参数，参数会被临时放到环境变量里
load_dotenv()

#2. 初始化模型
model = init_chat_model(
        model="模型名称",
        extra_body={"thinking":{"type":"disabled"}}
  )

#3. 创建智能体
agent = create_agent(model=model, tools=[工具函数名, 工具函数名,...], system_prompt="系统提示词", checkpointer=记忆存储位置)

#4. 调用智能体，得到是dict  {  "messages": 聊天记录列表 }，模型本次回复是列表里最后一条AiMessage对象
response = agent.invoke(  {
      "messages": [
             HumanMessage(content="......")
      ]
}  )

content = response['messages'][-1].content  #得到模型本次响应的内容
```

### 使用方式2：流式输出

```python
#1. 加载配置参数，参数会被临时放到环境变量里
load_dotenv()

#2. 初始化模型
model = init_chat_model(
        model="模型名称",
        extra_body={"thinking":{"type":"disabled"}}
  )

#3. 创建智能体
agent = create_agent(model=model, tools=[工具函数名, 工具函数名,...], system_prompt="系统提示词", checkpointer=记忆存储位置)

#4. 调用智能体，流式输出的方式。 得到stream
stream = agent.stream_events(
    input =  {
      "messages": [
             HumanMessage(content="......")
      ]},
    version="v3"
 )

for msg_stream in stream.messages:
     for text in msg_stream.text:
           print(text, end="", flush=True)
```

### 工具

#### 定义工具

**方式1：工具函数上添加 `@tool`**

```python
@tool("函数名", description="工具函数的作用描述", args_schema=模型类)
```

```python
class 模型类(BaseModel):
    函数参数名: 类型 = Field(description="", ...)
    ....
```

**方式2：不需要用 `@tool`，而是在函数内增加详细的文档字符串**

```python
def 函数名(形参, 形参, ..) -> 返回值类型:
    """
    函数的作用描述
    Args:
        形参名:  形参的描述
        形参名:  形参的描述
    Returns:
        返回结果的描述
    """
```

#### 注意事项

无论用哪种方式提供工具，都必须配置好：

- **工具的作用描述**：必须有
- **工具的参数描述**：
  - 可以没有，但一定做到见名知意
  - 如果参数较多或复杂，一定要有准确的参数描述

### MCP

模型上下文协议，利用这个协议可以让我们的智能体可以自由的调用其他人发布的工具。

#### 相关概念

| 概念 | 说明 |
| --- | --- |
| MCP Server | 提供工具的服务 |
| MCP Client | 用于获取工具服务的信息的客户端 |
| MCP Host | 协议管理客户端的应用，通常是我们的智能体 |

#### MCP 通信方式

**stdio：**

- 将工具下载到本机，在本机以子进程的方式运行起来，供智能体调用
- 纯粹的本机通信，几乎没有延迟

**streamable_http：**

- 通过 HTTP 协议的方式，与远程工具服务进行流式交互
- 通过网络进行数据的交互，所以存在一定的通信延迟，但是流式交互弥补了一些用户体验

#### 使用方式

```python
client = MultiServerMCPClient({
     "工具名称": {
          "transport": "通信方式",
           ......
      },
     "工具名称": {
         "transport": "通信方式",
          .....
      }
})
```

> 每个工具的配置信息，都来自于（魔搭 modelscope）的 mcp 服务提供的。

```python
tools = await client.get_tools()
```

### 记忆

#### 智能体的记忆分类

| 分类 | 说明 |
| --- | --- |
| 短期记忆 | 指会话记忆，一个会话内所有的聊天记录 |
| 长期记忆 | 相当于用户画像，跨会话的收集信息 |

#### 实现短期记忆

创建智能体时，设置记忆存储的位置：

```python
agent = create_agent(model=模型, tools=[], checkpointer=存储位置)
```

- 存储到内存：`InMemorySaver()`
- 存储到 PGSQL：`PostgresSaver()`

每次和智能体对话时，都要设置所属的会话 id：

```python
agent.invoke(
     input = {"messages":[HumanMessage(content="用户问题")]},
     config = {"configurable": {"thread_id":"会话id"}  }
)
```

#### 查看记忆状态

```python
#定义会话所属
Config = {"configurable":{"thread_id":"t1"}}
#调用会话
response = agent.invoke(
    {"messages":[HumanMessage(content = "我是练习时长两年的练习生蔡徐坤，喜欢唱跳Rap和篮球")]},
    config = Config
)
print(response["messages"][-1].content)
```

获取会话 agent 的记忆：

```python
agent_status = agent.get_state(Config)
print(agent_status)
```

删除会话记忆：

```python
#根据定义会话config的thread_id = t1删除记忆
agent.checkpointer.delete_thread("t1")
#删掉记忆后重新赋值并打印输出
agent_status = agent.get_state(Config)
print(agent_status)
```
