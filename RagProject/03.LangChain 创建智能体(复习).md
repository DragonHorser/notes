## 阻塞式输出

阻塞式输出，得到的结果是 dict 字典，其中有 `messages` 键对应的是消息列表，列表中最后一条消息是 AI 的最新回复。

```python
response = agent.invoke(
    input={"messages":[ HumanMessage(content="用户问题") ]},
    config={"configurable":{"thread_id":"会话id"}}
)
```

    config=Config,
    version="v3"
)
for message_stream in stream.messages:
    for text in message_stream.text:
