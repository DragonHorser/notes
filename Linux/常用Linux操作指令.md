# 👑 Linux & 全栈开发 终极命令速查表 (Cheat Sheet)

> **核心心法**：千万别死记硬背！记住前两个字母，剩下的全部靠 `Tab` 键补全。遇到不会的，直接 `Ctrl + F` 搜索。

## 📂 1. 文件与目录管理（基础）
*   `ls`：查看当前目录下的文件。
    *   `ls -l`：查看详细信息（权限、大小、时间）。
    *   `ls -a`：查看所有文件（包含以 `.` 开头的隐藏文件）。
*   `cd`：切换目录。
    *   `cd ..`：返回上一级。
    *   `cd /root`：进入绝对路径目录。
*   `pwd`：查看当前所在的完整路径。
*   `mkdir`：创建文件夹。
    *   `mkdir -p /a/b/c`：递归创建多级目录。
*   `rm`：删除文件或目录。**⚠️ 极度危险，Linux 无回收站！**
    *   `rm -rf ./文件名或目录`：强制递归删除（删库跑路专用）。

## 📄 2. 文件内容查看与编辑
*   `cat 文件名`：查看全部内容（仅限小文件）。
*   `less 文件名`：分页查看大文件（用 `上下键` 滚动，`q` 退出）。
*   `head -n 行数 文件名`：查看文件头部（如 `head -n 20 app.log`）。
*   `tail -n 行数 文件名`：查看文件尾部（如 `tail -n 20 app.log`）。
    *   **🌟 神级命令**：`tail -f 文件名`：实时追踪文件更新（看实时日志必备），按 `Ctrl + C` 退出。
*   `vim / vi 文件名`：强大的文本编辑器。
    *   `i`：进入**插入模式**（开始打字）。
    *   `Esc`：退出插入模式，进入**命令模式**。
    *   `:w`：保存。
    *   `:q`：退出。
    *   `:wq`：保存并退出。
    *   `:q!`：强制退出不保存（改乱了保命用）。
    *   `:set nu`：显示行号。

## 📦 3. 压缩与解压
*   `tar -zcvf 包名.tar.gz 需打包内容`：打包并压缩（`z` gzip压缩，`c` 创建，`v` 显示过程，`f` 文件名）。
*   `tar -xvf 解压文件名.tar.gz -C 目标解压路径`：解压（`x` 解压，`C` 指定解压目录，大写 C）。

## 🔍 4. 搜索三剑客（找东西不求人）
*   `grep "关键字" 文件名`：在文件内容里搜索。
    *   *实战*：`grep "ERROR" app.log` （专抓报错）。
    *   `grep -r "关键字" 目录`：递归搜索整个目录下的所有文件内容。
*   `find 路径 -name "文件名"`：在磁盘里找文件。
    *   *实战*：`find / -name "*.py"` （找系统里所有的 Python 文件）。
*   `which 命令`：查命令的安装路径。
    *   *实战*：`which python`

## ⚙️ 5. 进程与端口（排查死机、端口冲突）
*   `ps -ef | grep 关键字`：查看进程信息。
    *   *实战*：`ps -ef | grep uvicorn` （查后端服务是否在跑）。
*   `kill -9 进程ID`：强制杀死进程（程序卡死时的终极手段）。
*   `netstat -tulnp`：查看系统当前开启的所有端口。
    *   *实战*：查 8000 端口被哪个程序占了（报错 `Address already in use` 时用）。
*   `systemctl`：服务管理控制。
    *   `systemctl start/stop/restart 服务名`：启动/停止/重启服务（如 `docker`、`sshd`）。
    *   `systemctl status 服务名`：查看服务状态。
    *   `systemctl enable 服务名`：设置开机自启。

## 🌐 6. 网络下载与请求
*   `curl 网址`：在终端发 HTTP 请求（测接口神器）。
    *   *实战*：`curl http://localhost:8000/api/presets`。
*   `wget 下载链接`：下载文件。
*   `ping 网址/IP`：测试网络连通性。

## 💻 7. 系统监控（看机器累不累）
*   `top` 或 `htop`：动态查看 CPU 和内存占用（`htop` 需安装，彩色更直观，按 `q` 退出）。
*   `df -h`：查看磁盘空间使用情况（**极常用**，磁盘满了会导致服务崩溃）。
*   `du -sh *`：查看当前目录下，哪个文件夹或文件最占空间。

## 🔐 8. 权限管理（Linux 的命根子）
*   `chmod`：修改文件权限。
    *   *实战*：`chmod +x start.sh` （给脚本加上可执行权限，最常用）。
*   `chown`：修改文件的所有者和所属组。
    *   *实战*：`chown -R ubuntu:ubuntu /app`。

## 🛠️ 9. SSH 与远程操作
*   `ssh 用户名@IP地址`：远程连接另一台服务器。
    *   *实战*：`ssh root@192.168.150.101`。
*   `scp 本地文件 用户名@IP:远程路径`：通过 SSH 传输文件。
    *   *实战*：`scp test.py root@192.168.150.101:/root/`。

# 🚀 进阶篇：真实项目中的“杀手锏”（大厂高频）

## 🎯 10. 文本处理三剑客（awk, sed, sort）
> 别被这三个字母吓到，它们是处理日志、提取数据的终极武器。

*   `sort 文件名`：对文件内容进行排序。
    *   `sort -n`：按数字大小排序（默认是按字母排序）。
    *   `sort -r`：倒序排列。
*   `uniq -c`：**去重并统计次数**（极其好用！）。
    *   *实战*：`cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -n 10` （**神级命令**：一行命令找出访问日志里 IP 访问量最高的前 10 名，专门用来防黑客或者查刷接口的）。
*   `sed 's/原内容/新内容/g' 文件名`：**流编辑器（批量替换）**。
    *   *实战*：`sed -i 's/旧密码/新密码/g' config.ini` （直接把文件里的所有“旧密码”替换成“新密码”并保存，改配置文件神器）。
*   `awk '{print $列号}'`：按列提取文本。
    *   *实战*：`ps -ef | grep python | awk '{print $2}'` （只提取进程列表里第二列的 PID 号）。

## 🔍 11. 文件差异对比（改完代码查错）
*   `diff 文件1 文件2`：对比两个文件哪里不一样。
    *   `diff -y 文件1 文件2`：左右并排显示，看得更清楚。
    *   或者直接用 `vimdiff 文件1 文件2`（在终端里用彩色的方式对比，极其高级）。

## 📦 12. 软链接与硬链接
*   `ln -s 源文件 快捷方式名`：创建**软链接**（类似于 Windows 的创建快捷方式）。
    *   *实战*：`ln -s /usr/local/python/bin/python3 /usr/bin/python` （把 Python 的路径映射到系统环境变量里，解决“找不到 python 命令”的问题）。

## 📡 13. 端口与进程的“超级放大镜”
*   `lsof -i :端口号`：查看指定端口被哪个进程占用（比 `netstat` 更强大）。
    *   *实战*：`lsof -i :8000`。
*   `killall 进程名`：按名字杀掉所有同名进程（比 `kill -9` 方便）。
    *   *实战*：`killall uvicorn` （如果有多个 worker 在跑，直接全杀）。
*   `nohup 命令 &`：**后台运行程序（必考！）**。
    *   *实战*：`nohup python main.py > app.log 2>&1 &` （让程序在后台跑，哪怕你关掉 SSH 窗口，程序也不会停，日志输出到 app.log）。
*   `jobs`：查看当前终端后台运行的任务。
*   `fg`：把后台任务调回前台。

## 🌐 14. 网络排障进阶
*   `ping -c 4 网址`：只 ping 4 次就自动停止（防止一直刷屏）。
*   `traceroute 网址`：路由追踪（看看你的网络包在哪个节点卡住了）。
*   `telnet IP 端口`：**测试端口通不通（极常用）**。
    *   *实战*：`telnet 192.168.150.101 3306` （测试 MySQL 端口开没开，通了会显示 Connected，不通会报 Connection refused）。

## 💾 15. 磁盘与内存的深度查看
*   `free -h`：查看内存（Mem 和 Swap）的使用情况。
*   `df -i`：查看 **inode** 使用率。
    *   *避坑*：有时候服务器提示磁盘满了，`df -h` 显示还有空间，但就是写不进文件，多半是 `inode` 被大量小文件耗尽了，用这个查。
*   `mount`：查看当前挂载的硬盘和目录。

## 🐳 16. Docker 篇（日常必用）
*   `docker ps`：查看运行中的容器。
    *   `docker ps -a`：查看所有容器（包括死掉的）。
*   `docker logs -f --tail 50 容器名`：**实时看容器最后 50 行日志**（排查 Docker 报错必用）。
*   `docker exec -it 容器名 bash`：**进入容器内部**（相当于 SSH 进了容器这台小电脑）。
*   `docker rm -f 容器名`：强制删除正在运行的容器。
*   `docker rmi 镜像名`：删除镜像。
*   `docker system prune -a`：**一键清理所有**没用的镜像、容器、缓存（当你的虚拟机磁盘报警时，用它瞬间释放几十个G）。
*   `docker cp 容器名:/容器内路径 宿主机路径`：把容器里的文件复制到外面来。

## 🛠️ 17. 历史命令与快捷键（装X必备）
*   `history`：查看你敲过的所有历史命令。
*   `history | grep docker`：搜你以前敲过的 docker 命令。
*   `!!`：执行上一条命令（比如上一条命令忘了加 `sudo`，直接敲 `sudo !!` 就行）。
*   `Ctrl + C`：强制终止当前程序。
*   `Ctrl + Z`：把当前程序挂起到后台。
*   `Ctrl + L`：一键清屏（跟 `clear` 命令一样，但更快）。
*   `Ctrl + R`：**搜索历史命令**（按完直接打字搜，极其好用）。
*   `Ctrl + A`：光标瞬间移到命令的最前面。
*   `Ctrl + E`：光标瞬间移到命令的最后面。
*   `Ctrl + U`：一键删除光标前面的所有内容。
*   `Ctrl + K`：一键删除光标后面的所有内容。
